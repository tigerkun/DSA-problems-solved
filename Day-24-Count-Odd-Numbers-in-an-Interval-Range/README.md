# Day 24 - Count Odd Numbers in an Interval Range

## Problem

Given two non-negative integers `low` and `high`, return the number of odd integers between `low` and `high` (inclusive).

### Example

Input:
low = 3, high = 7
Output:

3

Dry Run

Input:

low = 3, high = 7

Calculation:

(7 + 1) / 2 - 3 / 2
= 8 / 2 - 1
= 4 - 1
= 3

Output:

3
Complexity Analysis
Time Complexity: O(1)
Space Complexity: O(1)
